# IT Certification Study Platform

A web-based platform for studying and preparing for IT certifications.

projeto/
├── css/
│   ├── style.css          # Estilos globais (header, footer, componentes comuns)
│   └── materiais.css      # Estilos específicos da página de materiais
├── js/
│   ├── auth.js            # Autenticação geral
│   ├── app.js             # Aplicação principal
│   ├── config.js          # Configurações
│   └── materiais.js       # JavaScript específico da página de materiais
├── index.html             # Página principal
└── materiais.html         # Página de materiais

## Structure
- `index.html` - Main application
- `css/` - Stylesheets
- `js/` - JavaScript files
- `materiais/` - Study materials
- `simulados/` - Practice exams

## Getting Started
Open `index.html` in a web browser.
