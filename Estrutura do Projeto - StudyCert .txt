🐛 SOLUÇÃO DE PROBLEMAS COMUNS
PROBLEMA: Upload não funciona

    Solução: Verificar conexão com Supabase, tamanho do arquivo (<100MB), permissões

PROBLEMA: Login não persiste

    Solução: Limpar cookies, verificar token de autenticação

PROBLEMA: Site não carrega no GitHub Pages

    Solução: Verificar configuração do branch, caminhos relativos

PROBLEMA: Responsividade quebrada

    Solução: Verificar viewport meta tag, media queries
